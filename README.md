# M.Sc. Thesis — Data Analytics - Lavanya Chinthakayala
University of Hildesheim, 2021

**Title:** Advanced Vision and Memory for traditional World Models

**Summary:** This thesis investigates improvements to the vision and memory 
components of World Models (Ha & Schmidhuber, 2018) for reinforcement 
learning. The core contribution is replacing the standard VAE vision component 
with advanced generative architectures — InfoVAE and β-VAE — to learn higher 
quality spatial and temporal representations of real-world environments. 
Improved visual representations implicitly improve the memory (MDN-RNN) 
component, leading to better simulated training data for deep RL agents.

**Keywords:** deep reinforcement learning, world models, generative models, 
VAE, InfoVAE, β-VAE, representation learning, simulation
